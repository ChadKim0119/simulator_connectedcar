# e-Care 시뮬레이터

발표용 e-Care 커넥티드 케어 3D 시뮬레이터입니다. 빌드 과정 없이 `index.html` 한 파일로 동작합니다 (Three.js r128을 cdnjs에서 불러옵니다).

현재 버전: **v0.2.5** · 화면 왼쪽 위 e-Care 버튼을 누르면 버전 기록을 볼 수 있습니다. 버전은 0.0.1씩 올립니다 (`index.html`의 `VERSIONS` 배열).

## 도시 시연 개선 (v0.2.5)
- 정보 흐름 범례에 노란 경고 신호를 추가했습니다.
- 일반 차량은 고객 차량과 출동 차량의 예상 경로 앞에서 감속·정지 후 다시 출발합니다.
- 출동 차량은 고객 차량 도착까지 경광등과 사이렌을 유지합니다. 효과음 OFF는 유지됩니다.
- 심각 경고 중 고객 차량을 가리는 건물은 반투명 처리하고 가림이 해소되면 복원합니다.
- 통화 중 양쪽 시설·차량과 연결선이 보이도록 대화 패널 공간을 고려해 자동 맞춥니다.
- 주요 시설은 떠 있는 툴팁 대신 옥상 입간판으로 표시합니다.
- 공원에 뛰노는 어린이와 강아지, 별도 공원에 아빠와 아들의 캐치볼을 추가했습니다.

## 음성 지원 범위 (v0.2.4)
- 한국어의 긴급 경고 → 25분간 연락 없음 → 상담원 배정 · 고객 응답 통화에서만 WAV 음성과 ON/OFF 버튼을 제공합니다.
- 다른 통화, 통화 대기, 일본어에서는 음성 조작 영역을 숨기고 텍스트만 표시합니다. 기본 기기 TTS는 사용하지 않습니다.
- 언어를 일본어로 바꾸거나 초기화·프로젝트 전환하면 녹음 재생이 즉시 중단됩니다.

## 한국어 녹음 음성 (v0.2.3 · 변경 기록)
- 긴급 경고 → 25분간 연락 없음 → 상담원 배정 · 고객 응답 장면에서 한국어 대사 5개를 `audio/ecare/` WAV로 재생합니다.
- 녹음이 끝나면 다음 대사로 진행하며, 음성 OFF·언어 변경·초기화·모드 전환 시 중단합니다.
- v0.2.4부터 다른 대사·일본어는 텍스트만 제공합니다. 녹음 재생 실패 시 안내와 함께 텍스트로 진행합니다.

## e-Care 통화 음성 · 한국어/일본어 (v0.2.2 · 이전 버전 기록, v0.2.4에서 지원 범위 변경)
- e-Care의 콜센터·딜러 통화에서 현재 표시된 대사를 순서대로 읽습니다. 각 대사의 음성이 끝나면 다음 대사로 넘어갑니다.
- 고객 통화 패널을 펼치고 아래의 **음성 ON/OFF**를 선택합니다. 기본 ON이며 선택은 브라우저에 기억됩니다. 효과음 설정과는 별개입니다.
- 패널 머리의 **한국어 / 日本語**를 선택하면 대화와 음성 언어가 함께 바뀝니다. 재생 중 언어를 변경하면 현재 문장을 새 언어로 다시 읽습니다.
- 기기/브라우저의 Web Speech API를 사용합니다. API 키나 서버 TTS 비용이 필요하지 않습니다. 기기에 설치된 한국어·일본어 음성과 브라우저 지원 여부에 따라 음질과 재생 가능 여부가 달라집니다.
- 사용 가능한 언어별 음성이 둘 이상이면 고객·상담원에 서로 다른 음성을 배정하고, 하나이면 같은 음성의 높낮이와 속도를 구분합니다.
- 재생 중인 대사를 강조합니다. 음성 OFF는 즉시 재생을 멈추며 다시 ON하면 다음 대사부터 읽습니다. 초기화·프로젝트 전환 시에도 중단됩니다.
- 음성 미지원·해당 언어 음성 없음·재생 실패 시 패널에 상태를 안내하고 텍스트 진행을 유지합니다.
- **WNG는 음성을 적용하지 않고 기존 실제 2초 통화를 유지합니다.** GS에도 적용하지 않습니다.

## WNG 딜러 직접 연결 · 통화 2초 (v0.2.1)
- 현재 ON인 WNG가 B·C만 있고 A가 없으면 MM(HU)·GSA 앱 전화가 딜러(또는 AI 콜)로 바로 연결됩니다. 모든 경고가 해제된 경우 그룹의 경고 이력으로 판단합니다.
- 딜러 직접 통화는 **통화 완료**로 종료되며, 콜센터 수신 팝업·상담 메모 DMS 이관·이관 완료 단계를 거치지 않습니다. 경고 Trigger의 DMS 데이터 전송은 기존대로 유지됩니다.
- A가 포함된 고객 전화와 25분 자동 아웃바운드는 기존 콜센터 경로를 유지합니다.
- WNG 통화의 실제 재생 시간은 **2초**입니다. 시뮬레이션 시계의 통화 경과 시간(인바운드 3분·아웃바운드 4분)은 유지합니다.

## 화면 구성
- **정보 영역 (왼쪽)** — 차량 상태, 경고등, SLA 타이머, 이벤트 로그
- **시뮬레이션 화면 (가운데)** — 3D 도시. 휠 · 핀치(두 손가락 · 트랙패드) · +/− 버튼으로 확대·축소, 드래그로 이동
- **정보 흐름 (오른쪽)** — 차량 → VDP(일본) → VEP(한국) → 차량 HU · 고객 휴대폰 · 콜센터 웹 · DMS
- **조작 패널 (아래)** — 시나리오 버튼. 시뮬레이션 화면과 정보 흐름 아래에 걸쳐 따로 놓여, 어느 패널을 접어도 그대로 조작할 수 있습니다

## 통화 기록 · 흐름도 압축 · 통화 패널 도킹 (v0.2.0)
- **통화 기록**: 새 통화가 시작되면 지난 통화 기록을 지우고 새로 쌓습니다. 펼친 통화 패널은 자동으로 접히지 않습니다(v0.1.9의 자동 접힘 제거). 완료 연출 카드는 통화 패널을 피해서 나옵니다.
- **서버 흐름도**: 행 간격을 줄여 세로 326 → 282로 압축하고 화면에서도 더 작게 표시합니다. 상태 표 · 범례도 압축했습니다.
- **정보 흐름 자동 맞춤**: 카드가 늘어 넘치면 ① 흐름도 높이(최소 150px) → ② 설명 문구 · 범례 숨김 → ③ 완료 기록의 오래된 줄 순으로 줄여, 출동 · 현장 도착 · 상담 메모 · 완료 단계에서도 세로 스크롤 없이 보이게 합니다 (1181px 이하 iPad 가로 포함, 820px 이하 세로 배치는 제외).
- **통화 패널 도킹**: "정보 흐름 크게"(1181px 이상)에서는 떠 있던 통화 패널이 서버 흐름도와 모니터링 카드 사이 열에 고정되고, 정보 흐름 패널 폭이 68%로 넓어집니다. 시뮬레이션 크게로 돌아가면 다시 떠 있는 패널이 됩니다.

## 통화 패널 언어 · 터치 · 완료 연출 (v0.1.9)
- **고객 통화 패널 언어 전환**: 패널 머리의 [한국어 | 日本語]로 대화 · 이름 · 상태 문구를 바로 바꿉니다. 지난 대화와 진행 중인 대화 모두 바뀌고, 선택은 브라우저에 기억됩니다.
- **자동 펼침**: 통화가 시작되면 접혀 있어도 패널이 펼쳐집니다.
- **정보 흐름 패널**: 서버 흐름도를 줄이고 카드 · 상태 표를 압축했습니다. 고객 대화창은 정보 흐름에서 빼고 통화 패널로 일원화했습니다(콜센터 통화 중에는 콜센터 웹 카드, 딜러 통화 중에는 DMS 카드 표시).
- **확대 · 축소 버튼**: 돋보기 +/−, 잠금 상태가 보이는 지도 고정, 자동 카메라 버튼. 터치 기기에서는 46px로 커집니다.
- **iPad · 터치**: 두 손가락 핀치 확대 · 축소(+ 이동), 더블탭 · 화면 확대 방지, 버튼 터치 영역 확대, 단축키 배지 숨김, WNG 매트릭스는 탭하면 상태가 표시됩니다.
- **케어 완료 연출**: 견인 차량(또는 고객 차량)이 서비스센터에 도착하면 빛 기둥 · 파동 · 불꽃 · 컨페티와 체크 애니메이션, 소요 시간 · 통화 수 요약 카드, 효과음이 나옵니다. 카드는 누르면 닫히고 약 7초 뒤 자동으로 사라집니다.

## 화면 계위 (v0.0.5)
- **1순위 · 시뮬레이션 화면 + 조작 패널**: 한 덩어리로 붙어 있고, 발표자가 고를 차례가 되면 조작 패널 테두리가 밝아지며 "선택하세요"로 바뀝니다. 자동 진행 중에는 흐려집니다.
- **현재 단계 설명**: 시뮬레이션 화면 하단 자막 하나로만 보여줍니다(정보 흐름 크게 모드에서는 흐름도 아래에 표시).
- **화면 상단 줄**: 차량 상태와 최근 이벤트 한 줄 → 왼쪽 패널을 접어 둬도 상황을 알 수 있습니다.
- **차량 · 이벤트 패널**: 서랍처럼 접고 펼칩니다(기본 접힘, `I` 키).
- **레이아웃 전환**: 시뮬레이션 중심 ↔ 정보 흐름 크게 (`L` 키).
- **지도 고정**: 자동 카메라를 멈추고 직접 이동 · 확대 · 축소(최소 15%, `G` 키).

## 패널 크기 전환 · 접기 (v0.0.7)
- **크기 전환**: 패널 위치(왼쪽 정보 · 가운데 시뮬레이션 · 오른쪽 정보 흐름)는 그대로 두고 폭만 바뀝니다. 전환할 때 폭이 부드럽게 늘고 줄어듭니다.
- **접기**: 차량 · 이벤트(`I`), 시뮬레이션(`V`), 정보 흐름(`B`) 세 패널 모두 접으면 얇은 세로 막대로 남고, 막대를 누르면 다시 펼쳐집니다. 시뮬레이션과 정보 흐름을 동시에 접을 수는 없습니다(하나를 접으면 다른 하나가 펼쳐짐).
- **시뮬레이션을 접으면** 정보 흐름이 넓게 펼쳐지고, 조작 패널은 아래에서 그대로 작동합니다.
- **지도 자동 고정**: 30% 이하로 축소하면 지도가 자동으로 고정되고(`지도 고정 (자동)`), 다시 30%보다 크게 확대하면 자동 해제됩니다. 직접 고정한 경우에는 해제되지 않습니다.
- 정보 흐름 접기는 모든 화면 폭에서 동작합니다(좁은 화면에서는 오른쪽 얇은 막대, 휴대폰 폭에서는 가로 막대). 시뮬레이션 · 차량 이벤트 접기는 1181px 이상에서 동작합니다. 패널 상태는 브라우저에 기억됩니다.

## e-Care UI 시나리오(화면정의서) 반영 (v0.0.6)
- 콜센터 웹 진입 경로
  - 차량 HU(MM) 전화 → 전화 수신 안내 팝업(CCW-EC-100_P1) [전화 받기] → 건 인계 → 고객 응대
  - 앱 · 휴대폰 일반 전화 → 전화 수신 안내 팝업(일반 전화, P3) [전화 받기] → 상담 이력의 컨택 전 건 [고객 응대 시작]
  - 25분 경과 → 유휴 상담사 자동 배정 → 경고 알림 팝업(P2, 05:00 타임아웃) [전화 걸기] → CTI 발신
- 25분 경과 후 🔵 상황 선택: 고객 응답 / 고객 미응답 3회(재시도 2회 · 후처리 5분 → SMS 자동 발송 → 상담 완료) / 유휴 상담사 없음(SMS 콜백 문자 → 자동 할당)
- 긴급 출동 중 🟢 상담 메모 → 서비스센터로 전달 ON → 서비스센터 선택(선호 1 + 근거리 4, 업무중 · 업무종료) → 상담내역 확인 → DMS 전송 → 이관 완료
- 정보 흐름 패널의 처리 상태: 콜센터 4종 · 긴급 출동 4단계 · 서비스센터 DMS 8단계

## 낮 / 밤 (딜러 영업시간)
- 밤에는 시계가 22:10, 딜러가 영업 종료 상태입니다. 콜센터는 24시간 그대로입니다.
- 정비 경고 + 밤: HU · 앱으로 딜러에 연락하면 ARS 안내 후 **연락 요청이 DMS에 접수** → `M` 다음 날 09:00까지 타임랩스 → **딜러가 고객 휴대폰으로 콜백** → 예약 · 입고.
- 긴급 경고 + 밤: 콜센터 대응은 같고, 견인 입고는 보관 후 다음 날 09:00 정비 착수로 표시됩니다.
- 야간 딜러 대응 기준은 기획서에 없어 가정으로 구성했습니다(영업시간 09:00~18:00).

## WNG 정보 흐름 (v0.0.8)
첫 화면의 **WNG 정보 흐름**(또는 상단 WNG 버튼)에서 시작합니다. WNG에서는 정보 흐름 · 차량 이벤트 패널 없이 보드를 화면 전체 폭으로 쓰고, 직접 구성(256칸)과 콜센터 웹 화면은 보드 오른쪽 패널에 필요할 때만 열립니다. 타이밍별 WNG 메시지 도식(10:00 · 10:10 · 10:15 · 10:20 → Contact)을 Trigger마다 한 칸씩 채워 가며 보여줍니다.

| 행 | 규칙 |
|---|---|
| 타이밍별 WNG 메시지 (VDP → TSP) | 001~006과 256은 항상 표시하고, 그 사이(007~255)에 ON · 변경된 WNG가 있으면 "...." 옆 "+N"을 눌러 상태와 함께 확인. 매 Trigger마다 256개 WNG의 ON / OFF 전체 상태 전송. 직전 메시지와 비교해 on [발생] · off [발생] · [유지] 표시. Rank(A · B · C)는 TSP에서 매핑 |
| MM | 마지막 정보만 팝업 단일 표출(그룹에서 처음 발생한 WNG 중 Rank 우선), TSP 제어가 아닌 MM 로직. 없으면 no show up |
| GSA | 해당 Trigger에서 On으로 변경 발생한 WNG로 교체(번호 순, 재발생 포함). 없으면 no show up |
| DMS (TSP → DMS) | VDP에서 받은 데이터 포맷(256개 전체 상태)을 그대로 전송하고 GROUP ID · MSG ID를 추가. 매 Trigger마다 MSG ID +1. 모든 WNG가 OFF여도 항상 전송 |

- **Group ID (WorkFlow ID)**: 열린 그룹이 없을 때(처음 또는 컨택 완료 후) 들어오는 첫 Trigger에서 생성합니다. 모두 OFF인 Trigger여도 생성되고, 열린 그룹이 있으면 그대로 유지합니다. 컨택이 끝나면(상담 완료 · 이관 완료) 그룹을 닫습니다. *(종료 조건은 가정 — 기획 확인 필요)*
- 25분 자동 아웃바운드와 고객 전화(MM · GSA)는 그룹에 경고가 한 번이라도 발생한 뒤부터 가능하며, 25분 기준은 그룹의 첫 경고 발생 시각입니다.
- **컨택 케이스**: MM [CTA] 전화(인바운드, 11.1.1.1) · GSA 앱 [CTA] 전화(인바운드, 11.1.1.3) · 그룹 생성 후 25분간 인바운드 없음 → 자동 아웃바운드(11.1.1.2, 다음 WNG 발생 시각이 25분을 넘으면 자동으로 먼저 실행) · 완료된 그룹 재문의(추가 메모)
- 컨택 통화는 실제 2초로 짧게 진행합니다(통화 패널에 통화 중 · 통화 시간 표시, 시뮬레이션 시각은 3~4분 경과).
- 콜센터 상담 메모는 서비스센터로 전달됩니다(DMS 이관 → 이관 완료). B·C 딜러 직접 통화는 메모 이관 없이 통화 완료로 종료됩니다.
- **기획 시나리오**: 10:00 001·002 발생 → 10:10 001 해제 · 003 발생 → 10:15 002·003 해제 → 10:20 003·004·005 발생 → (10:25 컨택) → 10:40 003·004·005 해제, 모두 OFF(Group 002 생성 · MSG 001) → 10:50 001·006 발생 → 11:00 007 발생. 이후는 임의 변화
- **WNG 직접 구성**(E): 001~030 매트릭스(번호 · Rank 표시, Rank 색이 연하게 깔림)를 눌러 ON / OFF를 고르면 아래 WNG status에 한 줄로 요약되고, 패널 안 [전부 OFF] · [이 상태로 WNG 발생]으로 바로 처리
- 칸을 넘치는 WNG는 "+N"으로 표시되고, 누르면 툴팁으로 전체 목록을 보여줍니다(MM · GSA · DMS · 메시지 · 선택 목록).
- 시간이 흐를 때 우상단 SIM 시계가 발광하고, 진행 후 "+10분 → 10:10" 배지가 잠시 표시됩니다.
- 색 체계: 무채색 바탕 + 강조색 1개(청록: 현재 · DMS 전송 · 활성) + 상태색(On 발생 파랑 · Off 발생 분홍 · 유지 보라). Rank · MM · GSA는 채도를 낮춘 톤으로 표시합니다.
- 행 순서: 타임라인 → WNG 메시지 → TSP 판정 → DMS → MM → GSA. MM · GSA 행은 행 이름 옆 버튼으로 접고 펼칠 수 있습니다(기본 접힘). 접히면 표출 코드만 한 줄로 요약합니다.
- 기획서 도식에 '?'로 표시된 MM 칸은 화면에도 '?' 표시

## 고객 통화 패널 (v0.1.0)
- e-Care · GS 시뮬레이션에서 항상 떠 있는 플로팅 패널입니다(WNG에서는 표시하지 않음). 자동으로 닫히거나 사라지지 않습니다.
- 머리 부분을 끌어 원하는 위치로 옮기고, 머리를 누르거나 ⌃ 버튼으로 접기 · 펼치기. 위치와 상태는 브라우저에 기억됩니다.
- 펼치면 화면 위에서 조작 패널 아래선까지 열리고(화면 밖으로 넘치지 않음), 접으면 머리 한 줄에 최근 대화가 미리보기로 표시됩니다.
- 통화가 시작될 때 패널이 접혀 있으면 자동으로 펼칩니다(직접 접어 둔 경우에는 그대로 둠).
- 통화 기록은 통화마다 구분선과 함께 누적되고, [기록 지우기]로 비울 수 있습니다.
