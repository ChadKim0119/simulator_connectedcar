# e-Care 시뮬레이터

발표용 e-Care 커넥티드 케어 3D 시뮬레이터입니다. 빌드 과정 없이 `index.html` 한 파일로 동작합니다 (Three.js r128을 cdnjs에서 불러옵니다).

현재 버전: **v0.1.1** · 화면 왼쪽 위 e-Care 버튼을 누르면 버전 기록을 볼 수 있습니다. 버전은 0.0.1씩 올립니다 (`index.html`의 `VERSIONS` 배열).

## 화면 구성
- **정보 영역 (왼쪽)** — 차량 상태, 경고등, SLA 타이머, 이벤트 로그
- **시뮬레이션 화면 (가운데)** — 3D 도시. 휠/+ - 버튼으로 확대·축소, 드래그로 이동
- **정보 흐름 (오른쪽)** — 차량 → VDP(일본) → VEP(한국) → 차량 HU · 고객 휴대폰 · 콜센터 웹 · DMS
- **조작 패널 (아래)** — 시나리오 버튼. 시뮬레이션 화면과 정보 흐름 아래에 걸쳐 따로 놓여, 어느 패널을 접어도 그대로 조작할 수 있습니다

## 화면 계위 (v0.0.5)
- **1순위 · 시뮬레이션 화면 + 조작 패널**: 한 덩어리로 붙어 있고, 발표자가 고를 차례가 되면 조작 패널 테두리가 밝아지며 "선택하세요"로 바뀝니다. 자동 진행 중에는 흐려집니다.
- **현재 단계 설명**: 시뮬레이션 화면 하단 자막 하나로만 보여줍니다(정보 흐름 크게 모드에서는 흐름도 아래에 표시).
- **화면 상단 줄**: 차량 상태와 최근 이벤트 한 줄 → 왼쪽 패널을 접어 둬도 상황을 알 수 있습니다.
- **차량 · 이벤트 패널**: 서랍처럼 접고 펼칩니다(기본 접힘, `I` 키).
- **레이아웃 전환**: 시뮬레이션 중심 ↔ 정보 흐름 크게 (`L` 키).
- **지도 고정**: 자동 카메라를 멈추고 직접 이동 · 확대 · 축소(최소 15%, `G` 키).

## 패널 크기 전환 · 접기 (v0.0.7)
- **크기 전환**: 패널 위치(왼쪽 정보 · 가운데 시뮬레이션 · 오른쪽 정보 흐름)는 그대로 두고 폭만 바뀝니다. 전환할 때 폭이 부드럽게 늘고 줄어듭니다.
- **접기**: 차량 · 이벤트(`I`), 시뮬레이션(`V`), 정보 흐름(`B`) 세 패널 모두 접으면 얇은 세로 막대로 남고, 막대를 누르면 다시 펼쳐집니다. 시뮬레이션과 정보 흐름을 동시에 접을 수는 없습니다(하나를 접으면 다른 하나가 펼쳐짐).
- **시뮬레이션을 접으면** 정보 흐름이 넓게 펼쳐지고, 조작 패널은 아래에서 그대로 작동합니다.
- **지도 자동 고정**: 30% 이하로 축소하면 지도가 자동으로 고정되고(`지도 고정 (자동)`), 다시 30%보다 크게 확대하면 자동 해제됩니다. 직접 고정한 경우에는 해제되지 않습니다.
- 정보 흐름 접기는 모든 화면 폭에서 동작합니다(좁은 화면에서는 오른쪽 얇은 막대, 휴대폰 폭에서는 가로 막대). 시뮬레이션 · 차량 이벤트 접기는 1181px 이상에서 동작합니다. 패널 상태는 브라우저에 기억됩니다.

## e-Care UI 시나리오(화면정의서) 반영 (v0.0.6)
- 콜센터 웹 진입 경로
  - 차량 HU(MM) 전화 → 전화 수신 안내 팝업(CCW-EC-100_P1) [전화 받기] → 건 인계 → 고객 응대
  - 앱 · 휴대폰 일반 전화 → 전화 수신 안내 팝업(일반 전화, P3) [전화 받기] → 상담 이력의 컨택 전 건 [고객 응대 시작]
  - 25분 경과 → 유휴 상담사 자동 배정 → 경고 알림 팝업(P2, 05:00 타임아웃) [전화 걸기] → CTI 발신
- 25분 경과 후 🔵 상황 선택: 고객 응답 / 고객 미응답 3회(재시도 2회 · 후처리 5분 → SMS 자동 발송 → 상담 완료) / 유휴 상담사 없음(SMS 콜백 문자 → 자동 할당)
- 긴급 출동 중 🟢 상담 메모 → 서비스센터로 전달 ON → 서비스센터 선택(선호 1 + 근거리 4, 업무중 · 업무종료) → 상담내역 확인 → DMS 전송 → 이관 완료
- 정보 흐름 패널의 처리 상태: 콜센터 4종 · 긴급 출동 4단계 · 서비스센터 DMS 8단계

## 낮 / 밤 (딜러 영업시간)
- 밤에는 시계가 22:10, 딜러가 영업 종료 상태입니다. 콜센터는 24시간 그대로입니다.
- 정비 경고 + 밤: HU · 앱으로 딜러에 연락하면 ARS 안내 후 **연락 요청이 DMS에 접수** → `M` 다음 날 09:00까지 타임랩스 → **딜러가 고객 휴대폰으로 콜백** → 예약 · 입고.
- 긴급 경고 + 밤: 콜센터 대응은 같고, 견인 입고는 보관 후 다음 날 09:00 정비 착수로 표시됩니다.
- 야간 딜러 대응 기준은 기획서에 없어 가정으로 구성했습니다(영업시간 09:00~18:00).

## 시연 흐름 (🔵 발표자 선택 · 🟢 자동 진행)
1. 🔵 첫 화면에서 **e-Care** 선택 (상단 e-Care / GS 버튼으로 언제든 전환)
2. 🔵 **경고등 (심각)** 또는 **경고등 (정비)**
3. 🟢 차량 TCU → VDP(일본) → VEP(한국) → OPW WNG 필터(중복 · VIN · 위치 · 정비) → 경고 정보 배포
   - 긴급: 차량 HU · e-Care 앱 · 콜센터 웹(CCW) · DMS
   - 정비: 차량 HU · e-Care 앱 · DMS (콜센터 제외)
4. 고객 연락
   - 긴급 🔵 **HU 팝업 [전화하기]** / **앱 [콜센터 전화하기]** → 🟢 콜센터 통화 (SLA 이내)
   - 긴급 🔵 **25분간 연락 없음** → 🟢 25분을 실제 5초 타임랩스 → 상담원이 고객 휴대폰으로 콜아웃
   - 정비 🔵 **HU 팝업 [전화하기]** → 🟢 선호 딜러(서초 서비스센터)와 통화
   - 정비 🔵 **앱에서 서비스센터 찾기** → 🟢 선호 · 근처 딜러 목록 → 🔵 딜러 선택 → 🟢 서비스센터 통화
5. 후속 조치
   - 긴급 🔵 **긴급 출동** → 🟢 출동 → 🔵 **서비스센터로 견인** → 🟢 DMS 전달 · 입고
   - 정비 🔵 **정비 예약 확정** → 🟢 DMS 예약 등록 · 고객 차량 입고
6. 🔵 **처음부터 다시**

정비 경고등은 콜센터 상담원이 대응하지 않으며, 앱의 [콜센터 전화하기]는 긴급 경고에서만 제공합니다.

## WNG 정보 흐름 (v0.0.8)
첫 화면의 **WNG 정보 흐름**(또는 상단 WNG 버튼)에서 시작합니다. WNG에서는 정보 흐름 · 차량 이벤트 패널 없이 보드를 화면 전체 폭으로 쓰고, 직접 구성(256칸)과 콜센터 웹 화면은 보드 오른쪽 패널에 필요할 때만 열립니다. 타이밍별 WNG 메시지 도식(10:00 · 10:10 · 10:15 · 10:20 → Contact)을 Trigger마다 한 칸씩 채워 가며 보여줍니다.

| 행 | 규칙 |
|---|---|
| 타이밍별 WNG 메시지 (VDP → TSP) | 매 Trigger마다 256개 WNG의 ON / OFF 전체 상태 전송. 직전 메시지와 비교해 on [발생] · off [발생] · [유지] 표시. Rank(A · B · C)는 TSP에서 매핑 |
| MM | 마지막 정보만 팝업 단일 표출(그룹에서 처음 발생한 WNG 중 Rank 우선), TSP 제어가 아닌 MM 로직. 없으면 no show up |
| GSA | 해당 Trigger에서 On으로 변경 발생한 WNG로 교체(번호 순, 재발생 포함). 없으면 no show up |
| DMS (TSP → DMS) | VDP에서 전송된 포맷(256개 전체 상태)을 그대로 전송하고 GROUP ID · MSG ID를 추가. 매 Trigger마다 MSG ID +1 (모두 해제된 경우도 전송) |

- **Group ID (WorkFlow ID)**: 열린 그룹이 없을 때 첫 발생으로 생성. 컨택이 끝나면(상담 완료 · 이관 완료) 그룹을 닫고, 이후 새 발생이 오면 다음 Group ID를 만듭니다. *(종료 조건은 가정 — 기획 확인 필요)*
- **컨택 케이스**: MM [CTA] 전화(인바운드, 11.1.1.1) · GSA 앱 [CTA] 전화(인바운드, 11.1.1.3) · 그룹 생성 후 25분간 인바운드 없음 → 자동 아웃바운드(11.1.1.2, 다음 Trigger 시각이 25분을 넘으면 자동으로 먼저 실행) · 상담 중 신규 WNG(같은 그룹 · 카드 NEW · 토스트) · 완료된 그룹 재문의(추가 메모)
- 상담 메모 전달 ON → DMS 이관(이관 완료), OFF → 콜센터 내부 메모(상담 완료)
- **기획 시나리오**: 10:00 001·002 발생 → 10:10 001 해제 · 003 발생 → 10:15 002·003 해제 → 10:20 003·004·005 발생 → (10:25 컨택) → 10:40 003·004·005 해제 · 001·006 발생(Group 002) → 10:50 256 발생 → 11:00 001 해제. 이후는 임의 변화
- **WNG 직접 구성**(E): 256칸 또는 번호 버튼으로 ON / OFF를 골라 바로 Trigger 전송
- 기획서 도식에 '?'로 표시된 MM 칸은 화면에도 '?' 표시
- 컨택 칸의 **통화 내용 보기**로 지난 통화를 다시 볼 수 있습니다

## 고객 통화 패널 (v0.1.0)
- e-Care · GS · WNG 모든 시뮬레이션에서 항상 떠 있는 플로팅 패널입니다. 자동으로 닫히거나 사라지지 않습니다.
- 머리 부분을 끌어 원하는 위치로 옮기고, 머리를 누르거나 ⌃ 버튼으로 접기 · 펼치기. 위치와 상태는 브라우저에 기억됩니다.
- 펼치면 화면 전체 높이로 열리고, 접으면 머리 한 줄에 최근 대화가 미리보기로 표시됩니다.
- 통화가 시작될 때 패널이 접혀 있으면 자동으로 펼칩니다(직접 접어 둔 경우에는 그대로 둠).
- 통화 기록은 통화마다 구분선과 함께 누적되고, [기록 지우기]로 비울 수 있습니다. WNG 컨택 칸의 [통화 내용 보기]는 해당 통화 위치로 이동합니다.
