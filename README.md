# e-Care 시뮬레이터

발표용 e-Care 커넥티드 케어 3D 시뮬레이터입니다. 빌드 과정 없이 `index.html` 한 파일로 동작합니다 (Three.js r128을 cdnjs에서 불러옵니다).

현재 버전: **v0.0.2** · 화면 왼쪽 위 e-Care 버튼을 누르면 버전 기록을 볼 수 있습니다. 버전은 0.0.1씩 올립니다 (`index.html`의 `VERSIONS` 배열).

## 화면 구성
- **정보 영역 (왼쪽)** — 차량 상태, 경고등, SLA 타이머, 이벤트 로그
- **시뮬레이션 화면 (가운데)** — 3D 도시. 휠/+ - 버튼으로 확대·축소, 드래그로 이동
- **정보 흐름 (오른쪽)** — 차량 → VDP(일본) → VEP(한국) → 차량 HU · 고객 휴대폰 · 콜센터 웹 · DMS
- **조작 패널 (아래)** — 시나리오 버튼

## 시연 흐름
1. 첫 화면에서 **e-Care** 선택
2. **경고등 (심각)** 또는 **경고등 (정비)** → VDP(일본) → VEP(한국) → 차량 HU · 고객 휴대폰 · 콜센터 웹 · DMS로 경고 정보 배포
3. 고객 연락 시나리오 선택 (SLA 25분)
   - **고객이 전화를 건다** → 고객 휴대폰 → 상담센터 인바운드 통화
   - **고객이 25분간 전화하지 않는다** → 25분을 실제 5초 타임랩스로 표시 → 상담원이 고객 휴대폰으로 콜아웃
4. 심각: **긴급 출동** → **서비스센터로 견인** / 정비: **정비 예약 확정** (또는 긴급 출동 요청)
5. 완료 후 **처음부터 다시**

## 단축키
| 키 | 동작 |
|---|---|
| 1 / 2 | 경고등 (심각) / (정비) |
| V | 고객이 전화를 건다 |
| C | 고객이 25분간 전화하지 않는다 |
| E | 긴급 출동 |
| S | 정비 예약 확정 |
| T | 서비스센터로 견인 |
| N | 낮 / 밤 전환 |
| + / - / 0 | 확대 / 축소 / 자동 카메라 복귀 |
| R | 초기화 |

## 로컬 실행
`index.html`을 브라우저로 열거나 `npx serve .` 로 실행합니다.
