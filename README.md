# e-Care 시뮬레이터

발표용 e-Care 커넥티드 케어 3D 시뮬레이터입니다. 빌드 과정 없이 `index.html` 한 파일로 동작합니다 (Three.js r128을 cdnjs에서 불러옵니다).

## 시연 흐름
1. 첫 화면에서 **e-Care** 선택
2. **경고등 (심각)** 또는 **경고등 (정비)** 선택 → 차량 → VDP → VEP → 상담센터 원격 진단
3. **상담원 전화 걸기** 또는 **상담원 전화 받기** → 통화 애니메이션
4. 심각: **긴급 출동** → **서비스센터로 견인** / 정비: **정비 예약 확정** (또는 긴급 출동 요청)
5. 완료 후 **처음부터 다시**

## 단축키
| 키 | 동작 |
|---|---|
| 1 / 2 | 경고등 (심각) / (정비) |
| C / V | 전화 걸기 / 전화 받기 |
| E | 긴급 출동 |
| S | 정비 예약 확정 |
| T | 서비스센터로 견인 |
| R | 초기화 |

## 로컬 실행
`index.html`을 브라우저로 열거나 `npx serve .` 로 실행합니다.
